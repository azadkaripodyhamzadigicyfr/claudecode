Example Module for Odoo 19

Overview

This is a simple example module that demonstrates the basic structure and features of an Odoo 19 custom module.

Features

Custom Model

Includes a complete example model (example.model) with various field types.

Multiple Views

Demonstrates Tree, Form, Kanban, and Search views with modern Odoo styling.

State Management

Implements a workflow with Draft, Confirmed, Done, and Cancelled states.

Security

Includes access rights configuration for different user groups.

Business Logic

Contains computed fields, constraints, and action methods.

Installation

  1. Restart your Odoo instance
  2. Update the Apps list
  3. Search for "Example Module"
  4. Click Install

Usage

After installation, you'll find a new "Example App" menu in the main navigation. From there, you can create and manage example records.

Learning Resources

This module serves as a template for creating your own custom Odoo modules. Study the code structure, views, and model definitions to understand Odoo development patterns.
